# Page QR Extension

Расширение Manifest V3 для Opera и Яндекс.Браузера. Оно добавляет в контекстное меню страницы пункт **«Показать QR-код страницы»** и выводит QR-код текущего URL поверх открытой вкладки.

## Возможности

- Генерирует QR-код для полного адреса страницы, включая query-параметры, `#fragment` и Unicode-символы.
- Не открывает новую вкладку и не перенаправляет пользователя.
- Работает полностью локально: нет сервера, внешних запросов, аналитики, хранения URL или сбора данных.
- QR-окно закрывается кнопкой ×, клавишей <kbd>Esc</kbd> или кликом вне окна.
- Повторный запуск заменяет уже открытое окно, а не добавляет ещё одно.

## Разрешения и приватность

| Разрешение | Для чего нужно |
| --- | --- |
| `contextMenus` | Добавляет команду в контекстное меню страницы. |
| `activeTab` | Даёт временный доступ только к вкладке, для которой пользователь вызвал команду. |
| `scripting` | Вставляет локальное QR-окно в эту вкладку. |

Расширение не запрашивает постоянный доступ ко всем сайтам (`host_permissions`), не отправляет URL куда-либо и не записывает их в хранилище браузера.

## Установка

### Opera

1. Откройте `opera://extensions`.
2. Включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку.

## Публикация и обновления

Расширение распространяется бесплатно через [Opera Add-ons](https://addons.opera.com/). Поле `update_url` в `manifest.json` указывает официальный сервер обновлений Opera. Благодаря этому пользователи Opera, а также Яндекс.Браузера, установившие расширение из Opera Add-ons, получают опубликованные обновления автоматически.

Для выпуска новой версии:

1. Увеличьте поле `version` в `manifest.json`.
2. Выполните проверки из раздела ниже.
3. Упакуйте **содержимое** папки расширения, а не саму папку: `manifest.json` должен находиться в корне ZIP. Для проверки состава пакета запустите из корня проекта:

   ```powershell
   python cli\package_extension.py
   ```

   Скрипт использует Git и `.gitignore`, исключает `.git`, `dist`, `tests` и `cli`, а затем проверяет, что `manifest.json` находится в корне ZIP. Исходный манифест в архиве не меняется. Готовый ZIP появится в `dist/`.

4. В Opera откройте `opera://extensions`, включите режим разработчика и нажмите **Pack Extension**. Выберите папку проекта; Opera создаст CRX-файл в её родительской папке. Сохраните созданный закрытый ключ `.pem` в надёжном месте: он нужен для последующих выпусков с тем же идентификатором расширения.
5. Загрузите CRX как новую версию в [кабинете разработчика Opera Add-ons](https://addons.opera.com/developer/), заполните карточку и дождитесь модерации.

Для последующих выпусков используйте тот же `.pem` при упаковке, увеличивайте `version` и загружайте CRX через функцию обновления в Opera Add-ons.

## Проверка

Откройте обычную HTTP(S)-страницу, щёлкните правой кнопкой мыши по свободному месту и выберите «Показать QR-код страницы». Проверьте QR камерой телефона. Повторный запуск обновляет окно; `Esc`, кнопка × и щелчок мимо окна его закрывают.

На `opera://`, `browser://` и других внутренних страницах браузера внедрение недоступно — расширение просто не изменит страницу.

Очень длинные URL, которые не помещаются в QR-код версии 40 с уровнем коррекции L, будут показаны с сообщением об ошибке вместо QR-кода.

## Генератор QR

В `content.js` встроено только алгоритмическое ядро [qrcodejs](https://github.com/davidshimjs/qrcodejs): выбор версии, Reed-Solomon и матрица QR версий 1–40. Его устаревшие DOM, Flash, SVG, table и canvas-рендереры не используются — расширение рисует возвращённую матрицу собственным canvas-кодом. Byte-encoding заменён на современный `TextEncoder` с ECI UTF-8, поэтому URL с Unicode декодируются корректно. Лицензионные уведомления приведены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Структура

```text
manifest.json  — Manifest V3 и минимальные разрешения
background.js  — регистрация и обработка команды контекстного меню
content.js     — локальная генерация QR и модальное окно
icons/         — исходная и browser-size PNG-иконки
```

## Проверка после изменений

```powershell
node --check background.js
node --check content.js
node -e "JSON.parse(require('fs').readFileSync('manifest.json', 'utf8')); console.log('manifest valid')"
```

Для независимой проверки, что QR действительно декодируется, а не только рисуется на canvas, установите тестовые зависимости и выполните регрессионный тест:

```powershell
python -m pip install numpy zxing-cpp
python tests/qr_decode_test.py
```

После изменения файлов нажмите кнопку перезагрузки на карточке расширения в `opera://extensions`.
